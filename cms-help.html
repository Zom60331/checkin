← 回場次管理

讓 CMS 名單直接進入簽到系統。

在安裝助手的同一個 Chrome／Edge 瀏覽器使用管理頁與 CMS。首次安裝完成後，之後只需在登入過期時重新登入 CMS。

  1. 取得管理者提供的 cms-assistant.zip，解壓縮並保留資料夾。
  2. 開啟 Chrome 的 chrome://extensions，或 Edge 的 edge://extensions。
  3. 開啟「開發人員模式」，按「載入未封裝項目／載入解壓縮」，選擇含有 manifest.json 的 cms-assistant 資料夾。若公司政策不允許安裝，請交由管理者處理，不要關閉公司保護設定。
  4. 回場次管理頁重新整理，登入管理密碼，確認顯示「匯入助手已連接」。
  5. 按「開啟 CMS 登入」，在 CMS 自己的頁面輸入帳密。不要將 CMS 帳密填入簽到管理頁。
  6. 按「從 CMS 匯入」，搜尋課程或直接填課程編號，核對筆數與異常資料後確認匯入。
助手只讀取你指定的課程與報名資料，不修改 CMS 訂單。帳密與登入憑證留在 CMS 瀏覽器；保存到簽到系統的是必要名單資料。同步需要安裝助手的電腦與可連線 CMS 的網路，匯入完成後，學員簽到與抽獎不需持續開著 CMS。

成功且講座金額大於 0 才納入資格。零金額成功單可能已轉場，會先排除；真正免費名額請核對後人工補充。零人數成功單、部分退款與缺資料也會列為待確認。需要補人或修正時，使用管理頁「檢查／補充／版本」，不要手改系統保存的名單版本。

活動前按「從 CMS 更新」取得最新名單；控制台的「更新報到狀況」只更新簽到紀錄。
